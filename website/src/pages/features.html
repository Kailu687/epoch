Features

What works today, and what does not yet

Every capability carries a status. in-progress means implemented and tested in the development build but not released as a stable version. planned means not available.

Dataset intelligence

  • CSV import with encoding and delimiter detection, size limits and bad-file rejection in-progress
  • Column typing, missing values, duplicate rows, ID-like and constant column detection in-progress
  • Target suggestions; task type inferred with an explanation, and a question when ambiguous in-progress
  • Leakage warnings: target-like names and single-column probes on training rows in-progress
  • Excel, Parquet, image and audio datasets planned

Evaluation integrity

  • Seeded stratified train, validation and test split, with split hash recorded in-progress
  • Preprocessing fit on training rows only in-progress
  • Model selection on validation data only; baseline always shown in-progress
  • Test set evaluated once per model; repeats need confirmation and are logged in-progress
  • Macro-F1, balanced accuracy, confusion matrix; MAE, RMSE, R² in-progress
  • Group-aware and temporal splits, cross-validation planned

Training and resources

  • Training in a separate worker process with per-candidate progress in-progress
  • Cancel stops the worker process in-progress
  • CPU, RAM and worker memory shown during training in-progress
  • Candidates: baseline, logistic or ridge regression, random forest, histogram gradient boosting in-progress
  • Hyperparameter search, GPU monitoring, pause and resume planned
  • Neural networks and fine-tuning planned

Experiments and export

  • SQLite history of datasets, experiments, candidates and models in-progress
  • Dataset copied with SHA-256; a changed file is detected before training in-progress
  • Export bundle: pipeline, schema, labels, config, metrics, requirements, inference code, checksum manifest in-progress
  • Exports use a pickle-based model file: load only bundles you trust limitation
  • ONNX or other non-pickle formats planned
  • Command-line interface for headless runs in-progress
