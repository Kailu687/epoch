Local-first ML training

Train and evaluate models without writing training code.

Epoch inspects your dataset, proposes a sound evaluation protocol, trains candidate models on your own computer, and exports the model with the pipeline needed to reproduce predictions.

Workflow

From dataset to exported model in five steps

  1. Import

    Open a CSV file. Content is sniffed and bounded; nothing in the file is executed.

  2. Inspect and validate

    Column types, missing values, duplicates and possible target leakage are reported as errors or warnings.

  3. Configure the task

    Choose the target. The engine proposes classification or regression and a split protocol, and you confirm.

  4. Train and evaluate

    Candidates train in a separate process with real progress. Selection uses validation data only; the test set is evaluated once.

  5. Export

    Get the model, preprocessing, input schema, label mapping, metrics and a runnable example.

Local-first

Datasets stay on your machine. Training needs no cloud account or subscription.

Reproducible

Seeds, split indices, data fingerprints and library versions are recorded with each experiment.

Leakage-aware

Preprocessing is fit on training data only, and the test set is protected from model selection.

Portable export

Bundles include schema, label map, metrics, requirements and an inference example. Model files should only be loaded from sources you trust.

Resource-aware

CPU and memory use are shown during training. GPU monitoring is planned.

Extensible

A provider interface is designed so new domains plug in without changing the core. The plugin API is planned.

FAQ

Questions

Can I download an installer?

There is no stable installer. The downloads page lists an unsigned development build as a zip, and shows a download button only for files that exist and match their checksum.

Does it send my data anywhere?

The training engine runs locally and does not require network access.

Will it find the best possible model?

No. It searches a limited, declared set of candidates under your budget, and reports what it searched.

Can it train neural networks?

Not yet. Neural and non-tabular domains are on the roadmap.
