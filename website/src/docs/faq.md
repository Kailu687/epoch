## Is there an installer?
Not yet. See the downloads page for the current release state.

## Does it upload my data?
The engine runs locally and does not require network access.

## Is the best model guaranteed?
No. Only a limited set of candidates is searched.

## Can I load a model someone sent me?
Treat model files like executable code. Do not load files from untrusted sources.
